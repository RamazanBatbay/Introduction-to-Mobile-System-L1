## Overview
A fully-featured object-oriented Vehicle Rental System developed as an Android application. The project leverages advanced Object-Oriented Programming (OOP) principles to model and manage a fleet of vehicles effectively.

### Features
* **Advanced OOP Architecture:** Establishes a robust domain model using abstract classes and interfaces to represent different vehicle types and behaviors.
* **Data Persistence:** Implements XML data persistence for storing and retrieving vehicle records reliably.
* **Multi-Criteria Sorting:** Allows for dynamic sorting of vehicles based on multiple criteria (e.g., price, type, fuel level).
* **Parking and State Management:** Manages state consistency for parking operations, utilizing bitwise logic for fuel states and garage management.
