## Overview
A simple Android guessing game application where the user has to guess a randomly generated number between 1 and 10.
It fulfills the requirements for Lab 3:
- The game validates user input (must be an integer, must be in the range 1..10).
- If the guess is incorrect, it hints whether the target value is larger or smaller.
- The game is won ONLY if the user guesses the correct number exactly on their 2nd attempt.
- If the user guesses correctly on any other attempt, the game restarts instantly and instructs the user to try again.
